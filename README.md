# Project 5 Backend

This is a Rust backend project generated by Fourbyfour.

## Getting Started

### Prerequisites

- Rust
- Docker (optional)
- PostgreSQL (if not using Docker)

### Running Locally

```sh
cargo build
psql -U postgres -d app_db -f migrations/V001_create_tables.sql
cargo run
```

### Running with Docker Compose

```sh
docker compose up --build
```
